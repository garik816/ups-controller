# Веб-інтерфейс ESP8266

`index.html` містить усі стилі, українські тексти та JavaScript. Інтерфейс працює
без інтернету; сторонні шрифти, бібліотеки та зовнішні ресурси не завантажуються.
Під час підготовки прошивки сторінка стискається gzip та вбудовується у flash.
Залежності Node.js на ESP8266 не потрібні.

Контракт запитів описаний у [docs/API.md](../docs/API.md). Інтерфейс перевіряє
очевидні помилки форми, але остаточне рішення щодо команди, сигналів і збереження
налаштувань приймає прошивка. Імена Wi-Fi та повідомлення журналу вставляються як
текст; порожнє поле пароля роутера зберігає попередній пароль.

## Перевірка у справжньому браузері

Необов'язковий тест `tests/test_web.cjs` потребує Playwright із встановленим
Chromium на комп'ютері розробника. Запуск із кореня репозиторію:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/test_web.cjs
```

Тест локально імітує HTTP API; справжній UPS не використовується. Перевіряються
команди, підтвердження вимкнення, блокування несумісних дій, оновлення токена після
скидання, збереження пароля роутера, пошук мереж, небезпечні символи в SSID і
журналі, відхилення прошивки, відновлення зв'язку та адаптивна верстка.

За потреби можна передати:

- `UPS_CHROMIUM_EXECUTABLE` — шлях до встановленого виконуваного файла Chromium.
- `UPS_CHROMIUM_MODULE` — шлях до ES-модуля дистрибутива `@sparticuz/chromium`,
  якщо стандартний браузер Playwright недоступний.
- `UPS_SCREENSHOT_DIR` — директорія для контрольних знімків екрана, наприклад
  `build/ui-smoke`.

Тест не перевіряє електричні входи, справжній Wi-Fi або запис flash. Для цього
потрібна апаратна перевірка прошивки на NodeMCU.
