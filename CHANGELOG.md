# Журнал змін

## 1.1.0 — 2026-11-25

- Додано схеми резистивних дільників і зовнішніх підтяжок для сигналів 0/5 В, а також вимірювання 12 В акумулятора до 14,4 В.
- Додано неблокувальне вимірювання A0 для ESP8266 та Nano, усереднення, виявлення застарілих/насичених показів і попередження з гістерезисом.
- У вебпанелі додано напругу, профілі дільника, поріг попередження та калібрування за мультиметром; на Nano — параметри у BoardConfig.h і Serial-команду v.
- Схема налаштувань 2 зберігає сумісність зі схемою 1: попередні параметри UPS і мережі залишаються, вимірювання батареї типово вимкнене.
- Зміни параметрів напруги, мережі та пароля не скидають фільтри або таймери UPS.
- Незмінний вебінтерфейс повторно використовує готовий gzip, щоб збирання з іншою версією zlib/Python не змінювало згенерований файл.

### Інструменти збирання

- Індекс ESP8266 завантажується з офіційного GitHub Release 3.1.2, щоб установка не залежала від доступності `arduino.esp8266.com`.
- Обраний URL застосовується до всіх команд ESP-збирання без зміни глобального конфігураційного файлу Arduino CLI; тайм-аут мережі для запуску — 180 с, якщо його не задано змінною середовища.
- Додано збирання обох плат на Windows через PowerShell у GitHub Actions.
- Нормалізовано переноси рядків вебсторінки при пакуванні на Windows.

## 1.0.0 — 2026-11-25

- Об'єднано варіанти Arduino Nano та ESP8266 у спільний проєкт із єдиною версією та спільним автоматом керування.
- Збережено базові параметри попереднього `ups_autostart`: фільтр 300 мс, очікування 10 с, натискання 2 с, перевірка запуску до 15 с, одна спроба на цикл у стандартному режимі.
- Додано підтвердження OFF протягом 2 с для захисту від коротких пауз індикаторів.
- Додано ручні команди запуску, вимкнення, перезапуску, скасування та відновлення автоматики.
- Додано обмежений режим підтримання UPS увімкненим і пріоритет ручного вимкнення.
- Для ESP8266 додано український вебінтерфейс, точку доступу `UPS_wifi` за адресою `192.168.7.1`, підключення до роутера та резервну AP.
- Додано збереження налаштувань, журнал подій, авторизацію, захист POST-запитів і вебоновлення ESP.
- Додано native-тести, консольне збирання через Arduino CLI, GitHub Actions для обох цілей та релізи за тегом версії.
